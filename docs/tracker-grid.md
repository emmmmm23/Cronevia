# Direct tracker grids

Walk durations, steps, quantities and counts now use selectable boxes. Clicking or dragging sets a cumulative total; the inline Exact total field preserves precise totals and large historical values. Each box's amount is adjustable. Recorded zero and unlogged days stay distinct. Selection is a draft until Save selection; Cancel restores the saved day. Keyboard users can move with the arrow keys and toggle with Space. Unsaved edits are protected when leaving.

Sleep has 24 hour boxes with a visible AM/PM header and noon divider. AM is midnight through 11:59 AM; PM is noon through 11:59 PM. Tap to toggle or drag to paint/remove hours. The notebook uses the full workspace width, and desktop columns expand to fit the paper. Phones use a month calendar and a selected-day editor, with all 24 hours wrapped into touch-friendly AM and PM sections. They do not inherit the wide desktop table. Numeric trackers use the same calendar with wrapped amount buttons. A single AM/PM header marks the desktop noon divider. Overnight blocks join evening and morning on their wake-up date. Existing fractional hours are hatched, and unchanged timestamps, timezone, sleep/nap type, notes, photos, awake adjustments and historical config are retained. Removing a middle block can split an interval; the existing note/photo stays with its first remaining interval. A save that would lose attached metadata is rejected with an explanation. Overlapping/invalid/future sleep still uses the existing server validation and rolls back.

The optional Note / photo action opens a compact sheet with the calendar-selected date shown as text, a note and private photo. The date is fixed in both notes and log modals. Choose another day on the calendar to edit that day. Numeric totals and sleep times stay on the paper. Habits have their own section and calendar: a clicked date opens Yes/No, notes and an optional photo. A checkbox on a combined habit page edits that habit while preserving the others. Setup no longer asks for weekdays; existing schedules remain intact.

Sleep is the default when marking hours. The optional Mark as a nap checkbox changes the kind being painted. Naps use a striped fill and retain their separate type after saving. Adjacent new hours extend the matching existing recording across midnight, preserving its identity and attached memories. Daytime sleep across noon is accepted. Future-ending selections give an explicit date/timezone explanation; new recordings use the account timezone automatically, falling back to the device timezone if the profile has none. There is no inline timezone selector.

Tracker stickers now use the whole paper. Legacy header coordinates are translated without moving the original artwork; edited placements are saved with `space: page`. The design preview includes a page body, and drag/keyboard controls reach the calendar's lower rows. Dragging near a viewport edge scrolls the page. These additions use the existing validated design storage and require no new migration beyond the grid migration below.

Apply `supabase/migrations/20261028000006_tracker_grid.sql` after the existing migrations. It adds `save_tracker_grid_day`, which locks the tracker, checks owner/MFA and expected row timestamps, validates and replaces a day's entries atomically, preserves original snapshot metadata, and rolls back on failure. The release build checks schema version `20261028.6` and anonymous write denial. No new credentials or public storage are needed.

Verification: `npm test`, `npm run test:database`, `npx playwright test --config playwright.trackers.config.ts`, `npm run check:tracker-grid -- --production`, `npm run build`, and the credential/build-artifact scan. Browser tests use isolated fixtures; the hosted probe checks schema capabilities without accessing real user records.

Tracker detail pages omit the collection hero and sidebar. A single Customize action opens appearance controls; More holds sticker arrangement, journal links and management actions. Monthly coverage is tucked below the paper. Starter pages and existing trackers keep their known logging type; only a blank custom tracker asks how to log. Sleep and Steps use their fixed units without showing an editable unit field. Optional goals are collapsed, and existing values are preserved.

The tracker experience is mobile first. Habit calendars have an 840px maximum width with proportionate cells. Saved notes and private photo thumbnails appear directly inside their matching calendar dates, including category calendars and the mobile measurement calendar. Longer notes and uncropped photos also appear in dated cards below. Previews wrap and clamp to fit each cell, and only weeks with attachments grow taller. Private photos use signed URLs and responsive, uncropped images; cards stack on phones and use columns on larger screens. Empty attachments are omitted, and older months are filtered out.
