🚀 Cronevia Supabase Setup

Your automated database setup assistant

Step 1: Open Supabase SQL Editor

Click the button below to open your Supabase SQL Editor in a new tab.

📋 What this does: Opens the SQL Editor where you'll run the database setup scripts.
Open SQL Editor →

Step 2: Copy Database Schema

Click the button below to copy the database schema to your clipboard. Then paste it into the SQL Editor and click "Run".

⚠️ Important: Make sure you copied the ENTIRE schema. The SQL Editor should show hundreds of lines.
Click "Copy Schema SQL" to load...

Step 3: Copy RLS Policies

In the SQL Editor, click "New query", then copy the RLS policies below and run them.

🔒 What this does: Enables Row Level Security to protect your user data.
Click "Copy RLS SQL" to load...

Step 4: Verify Tables Created

Go to the Table Editor to confirm your tables were created successfully.

✅ Expected result: You should see 17 tables including: profiles, user_settings, journal_entries, trips, memories, etc.
Open Table Editor →

Step 5: Get Your Anon Key

Copy your Supabase anon key and add it to your frontend/.env file.

⚠️ Important: Copy the "anon" or "public" key, NOT the service_role key!
Get Anon Key →
# Add these to frontend/.env: VITE_SUPABASE_URL=https://lrgxrfyzakehsnifypmd.supabase.co VITE_SUPABASE_ANON_KEY=your-anon-key-here

🎉 Setup Complete!
