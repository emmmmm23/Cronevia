================================================================================
🎯 WHAT YOU NEED TO DO
================================================================================

You have TWO options to create your Super Admin:

OPTION 1: PowerShell Wizard (Easiest - Recommended)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Open PowerShell and run:

  cd backend
  powershell -ExecutionPolicy Bypass -File setup-super-admin.ps1

This will:
  • Display a guided setup wizard
  • Ask for your name, email, password
  • Create your account
  • Verify success

OPTION 2: Artisan Command (Standard)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Open PowerShell and run:

  cd backend
  php artisan cronevia:create-super-admin

This will:
  • Ask for your name
  • Ask for your email
  • Ask for your password
  • Confirm password
  • Create your account

================================================================================
📋 INFORMATION YOU'LL NEED
================================================================================

Prepare these before starting:

1. YOUR FULL NAME
   Example: Juan Miguel
   Length: Any reasonable name

2. YOUR EMAIL ADDRESS
   Example: juan@cronevia.com
   Must be: Unique (not already used)
   Format: Valid email address

3. YOUR PASSWORD
   Must include:
     ✅ 8+ characters (12+ recommended)
     ✅ Uppercase letters (A-Z)
     ✅ Lowercase letters (a-z)
     ✅ Numbers (0-9)
     ✅ Symbols (!@#$%^&*)

   Examples that WORK:
     • SecurePass123!
     • Admin@Cronevia2024
     • MyPassword#99abc

   Examples that DON'T work:
     • password123 (missing uppercase + symbols)
     • PASSWORD! (missing lowercase + numbers)
     • Pass1 (too short)

🔧 STEP-BY-STEP SETUP
================================================================================

STEP 1: Open Terminal
━━━━━━━━━━━━━━━━━━━

  cd c:\Users\Juan Miguel\Cronevia\backend

STEP 2: Choose Your Method
━━━━━━━━━━━━━━━━━━━━━━━━━

OPTION 1 - PowerShell Wizard:
  powershell -ExecutionPolicy Bypass -File setup-super-admin.ps1

  1. Super Admin Name:
     → Type: Your full name
     → Press: Enter

  2. Super Admin Email:
     → Type: Your email
     → Press: Enter

  3. Password:
     → Type: Your strong password (won't display)
     → Press: Enter

  4. Confirm Password:
     → Type: Same password
     → Press: Enter

STEP 4: Success!
━━━━━━━━━━━━━━
You'll see:

================================================================================
❓ HELP & TROUBLESHOOTING
================================================================================

Problem: "Super Admin account already exists"
Solution: Only one allowed. Use: php artisan cronevia:replace-super-admin

Problem: "Email already exists"
Solution: Use a different email address

Problem: "Password too weak"
Solution: Use 8+ chars with uppercase, lowercase, numbers, symbols

Problem: "Passwords do not match"
Solution: Re-enter both carefully

Problem: Command times out
Solution: Run in interactive PowerShell terminal
